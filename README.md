## 학습 모드

- **📖 목록** — 카테고리 칩·검색·즐겨찾기 필터, 카테고리별 진도
- **🃏 카드** — 뜻을 보고 일본어 떠올리기, 탭하면 뒤집히며 자동 재생, 외웠어요/몰랐어요, 외운 카드 빼기
- **🎧 듣고 맞추기** — 음성만 듣고 뜻 4지선다, 정답이면 자동 다음 문제

외운 표시·즐겨찾기·재생 속도·여행회화/단어장 선택은 브라우저 `localStorage`에만 저장됩니다(서버 없음).

## 파일

```
index.html        페이지
styles.css        다크/네온 스타일 (모바일 퍼스트)
app.js            화면·오디오·학습 모드 로직
data/phrases.json 여행회화 문장 원본
data/words.json   기초 단어 원본 (30카테고리)
data.js           위 두 JSON을 페이지용으로 합친 결과 (build.py가 생성)
audio/*.mp3       문장 182 + 듣기 답변 12 + 단어 598 = 792
icon.svg / icon-192.png / icon-512.png / manifest.json   홈 화면 추가용
build.py          phrases.json + words.json -> data.js + 검증
make_words.py     words.json 생성용 원본 표(배포 안 함)
gen_audio.py      edge-tts 로 MP3 생성 (없는 파일만)
verify.py         로컬 HTTP 로 모든 경로 200 확인
verify_browser.py 여행회화 탭 동작·콘솔 오류 확인
verify_words.py   기초 단어장 탭 동작·콘솔 오류 확인
deploy.sh         빌드 후 GitHub main 브랜치로 push
```

## 문장·단어 추가

1. 문장은 `data/phrases.json` 의 `phrases` 에, 단어는 `data/words.json` 의 `words` 에 항목 추가.
   - 문장: `id`, `cat`, `level`, `ko`, `ja`, `kana`, `pron`, `tip` (듣기 카드는 `reply_*` 도)
   - 단어: `id`(`w-...`), `cat`(`w-...`), `kind:"word"`, `ja`, `kana`, `ko`, `pron`, `say`(음성으로 읽을 읽기), `tip`
2. `python3 gen_audio.py` — 새 id 의 MP3만 생성 (`--force` 로 전체 재생성, `--only word|talk` 로 범위 지정)
3. `python3 build.py && python3 verify.py` — data.js 생성과 경로 확인
4. `./deploy.sh` — 빌드 후 배포

## 배포

`./deploy.sh` 가 `work/study-hub/gh-pages` 체크아웃에 배포 파일만 복사해 `choijh00126-prog/study-hub` 의 `main` 으로 push합니다.
